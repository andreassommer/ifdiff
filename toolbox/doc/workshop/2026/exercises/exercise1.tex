\section*{Task 1: Introductory Example}

Consider the following switched ODE

\begin{equation}\label{eq:task1_rhs}
\begin{aligned}
\frac{d}{dt}x_1(t) &= 
\begin{cases}
	q_1(t), & \text{if } x_1(t) \leq 750 \\
	q_1(t) - q_2(t),  & \text{if } x_1(t) > 750 \\
\end{cases} \\
\frac{d}{dt}x_2(t) &= 
\begin{cases}
	0, & \text{if } x_1(t) \leq 750 \\
	-300, & \text{if } 750 < x_1(t) < 800 \\
	0, & \text{if } x_1(t) \geq 800 \\
\end{cases}
\end{aligned}
\end{equation}
where
\begin{equation}\label{eq:task1_rhs_helpers}
\begin{aligned}
q_1(t) &= \frac{50}{27}t^2 - \frac{100}{3}t + \frac{400}{3} \\
q_2(t) &= (1000 - x_2)(p_1(t-19) + p_2)
\end{aligned}
\end{equation}

\begin{enumerate}[label=\alph*)]
	
	\item \label{item:task1a} \textbf{Subtask:}\\
	Use \lstinline|ode45| to solve this system on the time interval $I = [0, 30]$ with initial conditions $x_1(0) = 0$ and $x_2(0) = 1000$. Use $p = (\frac{3}{4}, \frac{1}{4})$ as the parameter vector. \\
	Plot the solution. Does the solution look correct? Explain why \lstinline|ode45| produces this result. \\ \\
	\textbf{Steps:}
	\begin{enumerate}[label=\arabic*.]
		\item Implement the RHS in the file \texttt{rhsTask1.m} as described by \cref{eq:task1_rhs} and \cref{eq:task1_rhs_helpers}. Compute the values of $q_1(t)$ and $q_2(t)$ directly in the RHS as local variables \lstinline|q1| and \lstinline|q2| (do not implement them as separate functions).
		\item Set the integration time span, initial conditions and parameters in the file \texttt{runTask1.m}.
		\item Use \lstinline|ode45| to compute a solution. Remember to pass the RHS as an anonymous function \\\lstinline|@(t, y) rhsTaks1(t, y, p)|, which takes a timepoint and state vector and returns the derivative vector. Don't forget to provide the integration time span and initial conditions.
		\item Create a vector of timepoints where you will plot the solution using\\ \lstinline|t = linspace(tspan(1), tspan(end), 1000)|.
		\item Evalute the solution at the timepoints using \lstinline|yOde45 = deval(solutionOde45, t)|.
		\item Plot the solution using \lstinline|plot(t, yOde45)|, which will plot both solution components into one plot.
	\end{enumerate}

	\item \label{item:task1b} \textbf{Subtask:}\\
	Solve the system from subtask \ref{item:task1a} again, but this time with a maximum integrator step size of $0.1$. \\
	Plot the solution. Does the solution look correct? Explain why \lstinline|ode45| produces this result. \\ \\
	\textbf{Steps:}
	\begin{enumerate}[label=\arabic*.]
		\item Add the maximum step size to the integrator options using \\
		\lstinline|options = odeset(..., 'MaxStep', 0.1)|.
		\item Run your code from subtask \ref{item:task1a} with the new options.
	\end{enumerate}
	
	\item \textbf{Subtask:}\\
	Use IFDIFF to solve the system from subtask \ref{item:task1a}. \\
	Plot the solution. Does the solution match the solution computed in subtask \ref{item:task1b}? \\ \\
	\textbf{Steps:}
	\begin{enumerate}[label=\arabic*.]
		\item Use IFDIFF's \lstinline|prepareDatahandleForIntegration| function to prepare the RHS for integration. Don't forget to include the integrator and its options as optional arguments.
		\item Use IFDIFF's \lstinline|solveODE| function to solve the initial value problem.
		\item Create a vector of timepoints where you will plot the solution using\\ \lstinline|t = linspace(tspan(1), tspan(end), 1000)|.
		\item Evalute the solution at the timepoints using \lstinline|yIfdiff = deval(solutionIfdiff, t)|.
		\item Plot the solution using \lstinline|plot(t, yIfdiff)|, which will plot both solution components into one plot.
	\end{enumerate}
	
	\item We will now examine how the solution behaves under changes to the initial values, which is described by the initial value sensitivity matrix
	\begin{equation}
		G_y(t; y_0) = \frac{d}{dy_0} y(t; y_0) 
	\end{equation}
	where $y(t; y_0)$ is the solution of the system described by \cref{eq:task1_rhs} and \cref{eq:task1_rhs_helpers} for initial values $y_0$ at timepoint $t$.
	The entry $(G_y(t; y_0))_{i,j}$ in the i-th row and j-th column of the matrix describes how the i-th solution component changes when the initial value of the j-th solution component is disturbed. \\ \\
	\textbf{Subtask:}
	Compute the initial value sensitivities for the solution computed by \lstinline|ode45| in subtask \ref{item:task1b} by solving the Variational Differential Equations (VDE). \\
	Plot the result. Do the sensitivities look correct? \\ \\
	\textbf{Steps:}
	\begin{enumerate}[label=\arabic*.]
		\item Create a vector of timepoints for which you will compute and plot the sensitivities using\\ \lstinline|t = linspace(tspan(1), tspan(end), 1000)|.
		\item Use the provided function \lstinline|sensitivityOde45 = computeSensitivityOde45(solutionOde45, t)| to compute the sensitivities for the solution generated by \lstinline|ode45|.
		\item Use the provided function \lstinline|plotSensitivity(sensitivityOde45)| to plot the sensitivities.
	\end{enumerate}

	\item \textbf{Subtask:}\\
	Use IFDIFF to compute the initial value sensitivities. \\
	Plot the result. Do the sensitivities look correct? \\ \\
	\textbf{Steps:}
	\begin{enumerate}[label=\arabic*.]
		\item Create a vector of timepoints for which you will compute and plot the sensitivities using\\ \lstinline|t = linspace(tspan(1), tspan(end), 1000)|.
		\item Use IFDIFF's \lstinline|generateSensitivityFunction| function to create a function \lstinline|sensitivityFunction| which takes a vector of timepoints and returns the sensitivities at the given timepoints.
		\item Call the sensitivity function with \lstinline|sensitivityIfdiff = sensitivityFunction(t)| to compute the sensitivities at the timepoints.
		\item Use the provided function \lstinline|plotSensitivity(sensitivityIfdiff)| to plot the sensitivities.
	\end{enumerate}
\end{enumerate}
