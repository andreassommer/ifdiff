	\item ode45 produces incorrect results, because its accuracy depends on the smoothness of the ODE's right-hand side. For equations with non-smooth or even discontinuous terms, the solver fails to capture the true solution behaviour as can be seen in the plot below. Your code should look as follows:
	
	\textbf{Right-hand side} 
	\newline
	File name: rhsTask1.m
	\begin{lstlisting}
function dx = rhsTask1(t, x, p)
	dx = zeros(2, 1);
	q1 = 50/27*t.^2 - 100/3*t + 400/3;
	
	if x(1) <= 750
		dx(1) = q1;
	else
		q2 = (1000-x(2)) * (p(1)*(t-19) + p(2));
		dx(1) = q1 - q2;
	if x(1) <= 800
		dx(2) = -300;
	end
	end
	
end
	\end{lstlisting}
