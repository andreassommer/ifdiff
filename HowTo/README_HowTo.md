# HowTo Folder

This folder contains the Workhop Material (currently from the summer term Workshop 18.07.2025).
**Exercise_Workshop2025.pdf**: Offers tasks about learning how to work with IFDIFF in general (solving and sensitivity analysis), how to code State-Jumps, Filippov Sliding and an application with Parameter Estimation. It also provides tutorials and step-by-step solved examples in Appendix A and B.
**IFDIFF-Workshop-2025-Filippov_Slides.pdf**: Slides about the theory of Filippov Sliding Mode, Detection and Handling.
**how_to_use_ifdiff.pdf**: Offers an example on how to work with IFDIFF in general.
**IFDIFF-Workshop-2025-Slides-PartI.pdf**: Slides about the theory of switched ODEs and how IFDIFF works and why it is needed to solve switched ODEs in MATLAB.
**plotter.m**: Plotter helper function for Task 3.
**setup_ifdiff.pdf**: Explains how to setup IFDIFF on your computer and also how to use it with MATLAB Online.
**Solutions_Workshop2025.pdf**: Provides the solutions to Exercises_Workshop2025.
